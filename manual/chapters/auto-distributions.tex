\chapter{Automatic work distribution}\label{ch:auto-distributions}

\begin{center}
\fbox{\parbox{0.9\linewidth}{\textsc{Stub.} This chapter is written
together with the code it describes, which is not in the library yet.}}
\end{center}

We are concerned in this chapter with the choice of the distribution of HDA$^*$
from the problem itself, without a hand-made abstraction: the
graph-partitioning distributions GAZHDA$^*$ and GRAZHDA$^*$, which build the
abstract graph and cut it so as to balance the load and to keep the edges
inside a worker, the feature-based FAZHDA$^*$, the operator-based OZHDA$^*$ and
the dynamic DAHDA$^*$; and the measures by which the distributions are
compared, i.e., the search overhead (SO), the communication overhead
(CO) and the load balance (LB).
